## wslc-compose v0.1.0 — 首个公开版本

用标准 `compose.yaml` 驱动 **WSL Containers（`wslc`）**：在微软官方 `wslc compose` 发布之前，提供 `docker compose` 风格的体验。

### 一键安装（Windows PowerShell，无需管理员）

```powershell
irm https://raw.githubusercontent.com/DawnMagnet/wslc-compose-go/main/scripts/install.ps1 | iex
```

自动识别 amd64/arm64、校验 SHA-256、安装到 `%LOCALAPPDATA%\Programs\wslc-compose`、加入用户 PATH，并在 `$PROFILE` 中启用 `wslc compose`。指定版本：

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/DawnMagnet/wslc-compose-go/main/scripts/install.ps1))) -Version v0.1.0
```

### 功能

- **命令**：`up`（`-d`/`--build`/`--pull`/`--force-recreate`/`--no-deps`/`--remove-orphans`/`--scale`/`--wait`）、`down`（`-v`）、`ps`（`--services`/`--status`/`--format json`，含 HEALTH 列）、`logs -f`、`exec`、`run --rm`、`build`、`pull`、`config`、`start`/`stop`/`restart`、`version`
- **Compose 解析**：官方 compose-go v2，支持插值、`.env`、多 `-f` 合并、`extends`、`include`、profiles
- **字段映射**：ports、environment/env_file、bind/命名/匿名卷、tmpfs、networks（别名、internal、子网）、depends_on（started/healthy/completed）、healthcheck、build（args/target/多阶段）、资源限制、ulimits、DNS、**GPU**（`gpus: all` / `deploy.resources.reservations.devices`）、replicas/scale 等
- **无状态文件**：项目状态全部存在 `com.docker.compose.*` 容器标签上；配置哈希驱动增量重建
- **`--dry-run`** 打印将执行的 wslc 命令；**`--strict`** 对 wslc 无法实现的字段报错
- `up` 失败时自动回滚本次新建的资源；pull 对网络抖动自动重试

### 已验证

Windows 11 + wslc 3.0.1 真机回归：`up`/`up -d`/`down -v`/`ps`/`logs`/`exec`/`run`/`build`/`pull`/`--scale`、健康检查等待、匿名卷、GPU（CUDA 显存读写）。

### 已知限制

wslc 不支持重启策略、`privileged`、`cap_add`、`devices`、多网络、secrets/configs 等（警告忽略，`--strict` 报错）；GPU 仅支持 `all`。详见 README。
