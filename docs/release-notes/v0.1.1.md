## wslc-compose v0.1.1

Packaging and documentation release. No behaviour changes in the Compose engine.

### Install / upgrade (Windows PowerShell, no admin required)

```powershell
irm https://raw.githubusercontent.com/DawnMagnet/wslc-compose-go/main/scripts/install.ps1 | iex
```

Pin this version:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/DawnMagnet/wslc-compose-go/main/scripts/install.ps1))) -Version v0.1.1
```

Then open a new terminal:

```powershell
wslc-compose version     # main command, works in every shell
wslc compose version     # PowerShell sugar, forwards to wslc-compose
```

### Changes

- **Fixed: `wslc-compose` printed nothing in PowerShell.** v0.1.0 installed the PowerShell wrapper as
  `wslc-compose.ps1` next to `wslc-compose.exe`; PowerShell prefers `.ps1` over `.exe`, so the wrapper
  shadowed the binary. The wrapper is now `wslc-compose.profile.ps1`. Re-running the installer migrates
  existing installs automatically (removes the old file and rewrites the `$PROFILE` line).
- **Smaller downloads.** `wslc-compose-windows-amd64.exe` and `wslc-compose-linux-amd64` are packed with
  [UPX](https://upx.github.io/) 5.2.1 (`--best --lzma`), about 70% smaller. `checksums.txt` covers the packed files.
  arm64 binaries are left uncompressed because they are not smoke-tested on real hardware.
- **English-first docs.** README is now bilingual (English, then Chinese); architecture notes and release notes
  are in English. `wslc-compose` is documented as the primary command, `wslc compose` as PowerShell sugar.
- **Release pipeline.** `make dist` gained a `compress` step (`UPX=` disables it); `release.yml` installs a
  pinned UPX and smoke-tests the packed Linux binary before publishing.

### Assets

| File | Description |
|---|---|
| `wslc-compose-windows-amd64.exe` | Windows x64 (UPX-packed) |
| `wslc-compose-windows-arm64.exe` | Windows ARM64 |
| `wslc-compose-linux-amd64` | Inside WSL distros, x64 (UPX-packed) |
| `wslc-compose-linux-arm64` | Inside WSL distros, ARM64 |
| `install.ps1` | One-line installer / upgrader / uninstaller |
| `wslc-compose.profile.ps1`, `wslc-compose.sh`, `wslc.cmd` | `wslc compose` wrappers for PowerShell, bash/zsh and cmd |
| `checksums.txt` | SHA-256 of every asset |

> Note: some antivirus engines flag UPX-packed executables heuristically. If yours does, restore the
> original binary with `upx -d wslc-compose.exe`, or build an uncompressed one from source with `make dist UPX=`.
